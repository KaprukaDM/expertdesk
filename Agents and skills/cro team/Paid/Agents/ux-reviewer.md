# cro-ux-reviewer

**Definition:** `.claude/agents/cro-ux-reviewer.md`

Produces the **UX Review** deliverable — Standard and Premium tier only. A mobile + desktop UX review weighted toward mobile since that's most traffic for most stores, and (Standard) the 1 verification re-scan confirming the Funnel Audit's flagged drop-off points actually improved after fixes shipped.

Heatmap + session-recording analysis is a **bonus, not guaranteed** — real data if the client already has a tool connected (e.g. Hotjar, Clarity), flagged as a gap if not, never fabricated. The guaranteed Standard+ UX deliverable is [cro-ux-laws-auditor](ux-laws-auditor.md)'s UX Laws Audit, which has no external dependency.

Tools: `Read, Grep, Glob, Write, WebFetch`
