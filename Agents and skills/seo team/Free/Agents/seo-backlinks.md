# seo-backlinks

**Vendored from:** [claude-seo](https://github.com/AgricIDaniel/claude-seo) — `.claude/agents/seo-backlinks.md`
**Used in:** Free (universal, always runs) + Paid (Standard/Premium)

Backlink profile analyst using free and paid sources. Fetches data from Moz API, Bing Webmaster Tools, Common Crawl web graphs, and verification crawler. Merges multi-source data with confidence-weighted scoring.

**Scope note:** an analyst, not an outreach tool — produces a gap analysis + target list, never places links.

Tools: `Read, Bash, Write, Glob, Grep`
