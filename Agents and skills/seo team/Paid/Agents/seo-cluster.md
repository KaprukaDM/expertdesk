# seo-cluster

**Vendored from:** [claude-seo](https://github.com/AgricIDaniel/claude-seo) — `.claude/agents/seo-cluster.md`
**Used in:** Paid (all tiers) + Free (universal, always runs)

Semantic topic clustering analysis using SERP overlap methodology. Expands seed keywords, performs pairwise SERP comparison, classifies intent, designs hub-and-spoke content architecture, and generates internal link matrices. Feeds "target keywords" and the "keyword-to-page mapping" feature.

Tools: `WebSearch, WebFetch, Read, Write, Bash, Glob, Grep`
