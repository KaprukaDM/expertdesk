# social-media-brand-voice

**Definition:** `.claude/agents/social-media-brand-voice.md`

Produces the **Brand Voice & Style Guide** only — Standard and Premium tiers. A short, usable reference: tone (with a "sounds like / doesn't sound like" pair), do's/don'ts, visual notes, caption structure.

Output feeds directly into `social-media-content-calendar` when both run in the same order.

Tools: `Read, Grep, Glob, Write`
