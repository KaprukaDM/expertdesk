# social-media-reporting

**Definition:** `.claude/agents/social-media-reporting.md`

Produces **Reporting** only, at tier-scaled depth:

- **Basic** — 6-month rolling report with actionable insights
- **Standard** — + monthly action plan
- **Premium** — + custom organic growth playbook

Uses real Insights if an access token + Page ID has been supplied; otherwise public-profile estimates, flagged as directional. Never generates or requests a token itself. Every number gets a "so what."

Tools: `Read, Grep, Glob, Write, WebSearch, WebFetch`
