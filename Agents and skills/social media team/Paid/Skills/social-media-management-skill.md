# social-media-management (skill)

**Definition:** `.claude/skills/social-media-management/SKILL.md`
**Loaded by:** every specialist agent — this is the shared deliverable-content spec, not one agent's private rulebook

The deliverable scope and content spec each specialist follows, keyed to the Social Media Growth package tiers in `src/lib/services.ts`:

- **§1 Platform Audit** — profile setup, cadence, engagement, gaps; scales 1 / 2 / up to 5 platforms
- **§2 Content Calendar** — 15+2 (Basic) / 15+8 (Standard) / 18+15 (Premium) posts+Reels/Stories, Premium weighting toward Reels not extra posts
- **§3 Competitor Research** — Standard/Premium only
- **§4 Brand Voice & Style Guide** — Standard/Premium only
- **§5 Organic Growth Best Practices** — creative pipeline, placement-specific strategy, content mix, value content, NAP consistency, inspiration folder (steal-and-adapt), interest media over social media, content volume, boost-only-winning-content, tight hooks/CTAs, Content Flywheel (break one piece into many)
- **§6 Reporting** — 6-month rolling report → monthly action plan (Standard) → custom growth playbook (Premium)
- **§7 Ads Campaign Strategy** — Premium only, strategy/recommendations, not execution
- **Live-data architecture** — Meta Business Portfolio / System User / operator-supplied access token, described as a target, consumed only if the operator hands one over; no agent generates or requests one itself
- **Fixes-implemented count** (5/10/15 per tier) — tied to the brand study's prioritized checklist; delivered as ready-to-apply artifacts, not live platform changes (no write access exists)

See the roster in the team [README](../README.md) for which agent owns which section.
